# История версий

## 2.1.0+40 — 3D на заставке (Этап 1)

Подключён 3D-движок и тестовая модель в верхней части заставки.

- Добавлена зависимость `model_viewer_plus: 1.7.2`
- В верхней части заставки — контейнер с 3D-моделью (тестовая модель Astronaut)
  в премиальной рамке с золотой окантовкой и бейджем «3D ПРОСМОТР»
- Модель можно вращать пальцем, включено авто-вращение
- Нижняя часть заставки (логотип, прогресс, лог, кнопка) не тронута
- Логика обновления приложения не тронута

## 2.0.1+39 — Исправление сборки

Сборка падала из-за несовместимости кода с Flutter 3.24.0 (версия в GitHub Actions).

- `Color.withValues(alpha: x)` → `Color.withOpacity(x)` — метод `withValues` появился только в Flutter 3.27
- `CardThemeData` → `CardTheme` — тип `CardThemeData` появился только в Flutter 3.27
- Правки в `lib/theme.dart`, `lib/main.dart`, `lib/wizard_screen.dart`
- Логика обновления приложения не тронута

## 2.0.0+38 — Новый старт

Полная переработка приложения с нуля. Премиальный дизайн уровня элитного B2B-софта.

### Новая архитектура
- Старая форма замера, чертежи, шаблоны и сервис удалены полностью
- Приложение построено заново: тема → заставка → меню → мастер замера

### Премиальная тема (`lib/theme.dart`)
- Палитра: глубокий графитово-синий (#0B1522 / #0F1B2D) + золото и бронза (#C9A227 / #B08D57)
- Светлая тема — элегантный минимализм с мягкими тенями
- Типографика: 11 стилей, плотные веса, аккуратный трекинг
- Компоненты: карточки (радиус 22, мягкая тень), поля ввода с золотой рамкой фокуса,
  чипы, снекбары, нижние панели, плавные переходы экранов
- Общие элементы: `AppUi.sectionTitle` (золотая черта + КАПС), `AppUi.darkPanel` (тёмная градиентная панель)

### Заставка
- Тёмный фон, золотой логотип со свечением
- Пошаговый лог загрузки (6 этапов) с прогресс-баром
- Проверка обновления при запуске (логика не изменена)

### Главное меню
- Премиальная шапка: тёмный градиент, логотип, золотая черта, переключатель темы
- Карточки разделов с каскадным появлением, цветными плитками-иконками и свечением
- Разделы: Создать замер, Сохранённые замеры, Настройки прайса, Сервис и ремонт, Проверить обновление

### Мастер замера (новый)
- `lib/wizard_screen.dart` — пошаговый мастер
- Шаг 1: Данные клиента (Имя, Телефон, Адрес) в премиальном стиле + кнопка «Далее»
- Шаг 2: заглушка (изделия — в следующих версиях)
- Общая шапка мастера с номером шага и полосой прогресса

### Сохранено без изменений
- Автообновление приложения (`lib/update_checker.dart`)
- Сборка APK через GitHub Actions
